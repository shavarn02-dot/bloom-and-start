| **RC-07** | Transactional Quota Enforcement | `usage_events` logged usage after execution | No pre-call quota reservation. Concurrent requests could bypass limits. | `workers/api/src/guardrails.ts`<br>`workers/api/src/index.ts` | **P0 (Critical)** | Implement `reserveQuotaTransactionally()` that checks & reserves daily/monthly quotas BEFORE executing expensive calls. |

| **RC-09** | SSRF Hardening | `isSafeUrlForFetch` checked hostname strings | No DNS resolution check, redirect revalidation, IPv6 loopback (`::1`, `fc00::/7`), or response-size limits. | `workers/api/src/guardrails.ts` | **P0 (Critical)** | Add IPv6 subnet blocking, redirect revalidation, maximum response size limits (5MB), and request timeouts. |
| **RC-10** | Conservative Entity Resolution | Matches with score >= 85 merged automatically | Name-only matches without matching registration ID or domain could merge distinct companies. | `modal/entity_resolver.py` | **P1 (High)** | Enforce strict matching rules: merge only if Registration ID, Source Record ID, Domain, or Exact Phone+Address match. | **RC-11** | Real ICP Scoring | Default ICP fit score passed as static 80/90 | No dynamic multi-field scoring against user's Business Profile parameters. | `modal/freshness_engine.py` | **P1 (High)** | Build multi-attribute ICP matcher comparing industry, sub-industry, roles, company size, location, and keywords. |
| **RC-13** | Website Change Detection | Page fetch re-extracted contacts even if unchanged | No content hashing check to bypass LLM extraction when content is identical. | `modal/pipeline.py` | **P1 (High)** | Compute sha256 hash of page content. | **RC-14** | Explicit Contact Verification Statuses | UI showed basic "Verified / Unverified" labels | Synthetic verification labels used without checking stored verification evidence. | `src/routes/app.leads.tsx` | **P1 (High)** | Map statuses explicitly to `Verified`, `Partially verified`, `Unverified`, `Stale`, `Suppressed`. |
| **RC-15** | UX Infrastructure Abstraction | UI exposed technical terms (`Crawl4AI`, `Playwright`, `Modal`, `MCA`, `SEC`) in main flow | Exposing internal worker details in user-facing search controls. | `src/routes/app.campaigns.new.tsx` | **P2 (Medium)** | Replace technical terms with user concepts: **Smart Search** and **Deep Search**. | **RC-16** | Database-First Orchestration | Campaign creation forced live scraping flow by default | Frontend campaign form did not use database-first search automatically. | `src/routes/app.campaigns.new.tsx`<br>`workers/api/src/index.ts` | **P2 (Medium)** | Make Database-First Search the default orchestration path for all new searches. |
